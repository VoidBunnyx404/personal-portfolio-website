PERSONAL PORTFOLIO WEBSITE
===========================

This project is made using HTML, CSS and JavaScript.
Comments have been added throughout the files to explain what each section does.

FILES IN THIS FOLDER
--------------------
1. index.html
   Contains the content and structure of the website.
   HTML comments explain the different website sections.

2. style.css
   Controls the colours, fonts, spacing, cards, buttons and page layout.
   Comments explain each group of CSS rules.

3. script.js
   Adds dark/light mode, mobile navigation, active navigation links,
   contact form validation and the current year in the footer.
   Comments explain each JavaScript feature.

4. profile.jpg
   Optional profile photograph. Add your own photo with this exact filename
   in the same folder as index.html.

HOW TO OPEN THE PROJECT IN VS CODE
----------------------------------
1. Download and extract the ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder.
4. Select the personal-portfolio-website folder.
5. Open index.html.
6. If you have the Live Server extension, right-click index.html and select
   "Open with Live Server".
7. Otherwise, open index.html in your web browser.

WHAT YOU SHOULD EDIT
--------------------
- Replace Your Name and YourName with your own name.
- Change the introduction and About Me information.
- Add your school, college, course and academic year.
- Update the skill names and percentages.
- Replace the sample project names and descriptions.
- Add your own hobbies and achievements.
- Change the email, GitHub and LinkedIn links.
- Add your own profile photo as profile.jpg.

HOW TO CHANGE SKILL LEVELS
--------------------------
In index.html, each skill has a percentage number and a progress bar width.
For example:
  <span>HTML</span><span>70%</span>
  <span style="width:70%"></span>

Change both 70% values to the percentage you want.

IMPORTANT NOTE ABOUT THE CONTACT FORM
-------------------------------------
The contact form checks whether the fields are filled in correctly and
displays a success message. It does not actually send emails. A backend
or email service is needed to send real messages.
